## 本轮修复与验收调整

1. 修复已在另一标签页消费的转写草稿无法放弃或重录的问题。客户端在收到明确的 `transcription_consumed` 后再查询服务端状态，核实后仅解除本地关联；查询失败时保留草稿和恢复编号，重试成功后清除旧错误。新增四项针对性回归，并完成实际双标签页验收。
2. 校正 README 配置创建命令、开发文档 Python 版本与仓库链接、包元数据链接，以及 API 文档中过时的发音评分与音素错误示例。补充常见私有 dotenv、TLS 私钥和浏览器身份文件的忽略规则。
3. 将复习浏览器脚本的仓库、业务与公开投影统一到独立测试时钟；原子更新测试时钟，并显式选择保留测试音频后再验证模拟多日回放。补充点餐与酒店的四道迁移题及评价上下文核对。
